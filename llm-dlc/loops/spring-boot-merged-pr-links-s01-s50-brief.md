Hold a reference, close the context, and inspect membership and `isClosed()`.

**Evidence and limits.** The old closer captures `getBeansOfType` at construction. The landed tests call the post-processor and closer with mocks. An assertion on `close()` alone misses a global strong reference. The maintainer explicitly removed the proposed change to the default for tests. Context collection by the GC is outside the membership claim.

**Technical notes.** `module/spring-boot-micrometer-metrics` uses Micrometer’s `Metrics` global composite. Use distinct bean and meter names and an isolated JVM or restore only the fixture’s memberships. Keep the Boot post-processor active for the late instances.
