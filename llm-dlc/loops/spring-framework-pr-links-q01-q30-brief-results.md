## Reproduction and limits

Each example has its caller, registered predictions, classpaths, input digests, and both JVM outcomes. Run `python3 examples/tools/build.py 508` for an individual example, substituting its number. Run `python3 verification/merged-pr-links/audit.py --campaign q01-q30` for the offline audit. Its `--replay` option rebuilds all callers and repeats every history.

Twenty-two comparisons use both complete module builds. Q04, Q10, Q17, Q18, Q19, Q20, Q25, and Q26 use each pin’s changed classes with the same released companions on both sides. The audit verifies loaded class origins and every class in each prepared slice against the setup inventory. Q04’s brief-lived public AutowireUtils entry was renamed before release. Q18’s base already contains some range support. Q26 uses Reactor 3.3.0.M1 because the snapshot from that date is unavailable. The other dated snapshots are listed in the build record. [Setup, alternatives, and digests](spring-framework-pr-links-q01-q30-brief-setup.md)

Q05 compiles one Kotlin source twice with the pinned Kotlin 2.3.20 compiler so each binary incorporates its own Spring inline extension. Its Java caller bytes are identical. Q11 uses the setup’s PostgreSQL 0.8.8.RELEASE R2DBC driver, its 0.9.20.RELEASE Reactor Netty transport, and the original Spring classpaths against the local PostgreSQL 17 image. Q21 uses the published Spring Test 7.0.10 client JAR on both sides. The JAR and its Maven Central SHA-256 are recorded in the example’s runtime lock. Q24 uses a fresh in-process Artemis 2.42.0 broker per history. Its result applies to that provider. Q30 runs on Linux with native absolute paths.

## Findings for upstream review

The second equal value in the public composite map view cannot be removed through that view. Its API documents partial mutability. A JDBC limit of zero suppresses all rows across three query forms. Reactive retry overflows converting a large, representable duration to nanoseconds. Direct legacy composite-listener calls silently skip their delegates.
