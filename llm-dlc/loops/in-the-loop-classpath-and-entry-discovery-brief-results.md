## Reproduction

Stage 3 accepts the two prepared manifests, the pinned JDK, and the frozen questions. With the original Log4j cache available, the following commands write a scaffold and consume it in a public replay. The last command checks the saved evidence offline. It also verified all five archived reports after extraction with the JDK and checker unavailable.

```sh
case_dir=lib/benchmark/organic-composition/log4j
subject_jdk="$HOME/.sdkman/candidates/java/21.0.13.0+9-tem"
out="$TMPDIR/log4j-entry"
python3 examples/tools/scaffold_example.py bind --before "$case_dir/old/prepared.json" --after "$case_dir/new/prepared.json" --jdk "$subject_jdk" --workflows "$case_dir/workflows.json" --output "$out/scaffold.json"
python3 examples/tools/build.py --change-plan application --before "$case_dir/old/prepared.json" --after "$case_dir/new/prepared.json" --jdk "$subject_jdk" --workflows "$case_dir/workflows.json" --previous "$out/scaffold.json" --cache "$out/cache" --output "$out/replay.json" --run
python3 examples/tools/build.py --change-plan bindings "$out/replay.json" --verify-receipts
```

An unknown deployment layout needs the original URL-to-artifact mapping. Competing public observations need the claim owner's intent. An indirect call whose dispatch is unresolved needs a trace on the original input. Parquet's first ranking preserves that last gap. These stops have separate records from the strict timezone proof.
