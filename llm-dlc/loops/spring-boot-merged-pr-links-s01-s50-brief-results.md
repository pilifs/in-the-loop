# Spring Boot S01–S50

Across 50 merged Spring Boot PRs, 142 of the 150 registered predictions matched the observed merged behavior, four were refuted and four public histories remain open. All 50 controls met their predictions on both revisions. Of the 47 intent histories measured on both sides, 45 distinguished the parent and merge. S11 and S46 preserved the predicted intent behavior. The S46 overlapping-index challenge distinguished the revisions. ## Where the merged behavior differed from the prediction

- **S08.3, message bundles.** The ordinary indexed pair resolved. Looking up the fixture whose basename contains a literal comma still returned `MISS`. [Example 595](../../examples/595-boot-indexed-message-bundles/README.md)
- **S26.1, Caffeine retrieval.** Async mode worked. The cache hit returned a `Cache.ValueWrapper` containing the expected string. The registered predicate required the string directly. [Example 613](../../examples/613-boot-caffeine-async-retrieval/README.md)
- **S33.3, health aliases.** Both exact aliases returned their own markers in both orders. The deeper component request returned HTTP 404. [Example 620](../../examples/620-boot-health-group-longest-alias/README.md)
- **S44.3, nested JAR metadata.** Reading the class first exposed package version `1.2.3`. Performing the optional lookup first left the package version null in a fresh process with the same archive. [Example 631](../../examples/631-boot-nested-package-version/README.md)

## How to read and repeat these results

The ordinary callers compile against the parent. Each runs the same compiled caller on the two original deployments using pinned JARs, provider identities and fixture inputs. The recorded examples expose the commands for their original external builds and verify archived result digests through `python3 examples/tools/build.py NUMBER`. The campaign audit checks every claim ID, revision and verdict against the brief and the evidence. Run `python3 verification/merged-pr-links/s01-s50/audit.py` for the full accounting, or add `--replay-case S01` for one JVM comparison.
