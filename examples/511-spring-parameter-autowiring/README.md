# Resolve an individual reflected parameter from outside Spring Test

An external consumer on the landing resolved a qualified method parameter to west. Reusing one generic declaration with two containing classes selected the corresponding west and east singletons.

The Jupiter control exercised SpringExtension on both revisions. These exact AutowireUtils signatures were subsequently replaced before a published release.

Each pin supplies its changed production classes on spring-5.2.0.M1-q04. The replay verifies the loaded class origins and all class digests of each compiled slice.
