# A UTF-8 decoder across every byte partition

The finite corpus contains every string of up to three code points from A, é and 😀 and every partition of its encoded bytes. A BOM-prefixed transfer first strips the mark with the fully built Commons IO repair. Raw UTF-16 units and a separate end-of-input read are retained for all 5,578 inputs.
