# Public stock factories and shared backup identity

`Checkout.Pair.open` clamps the initial count and chooses shared or distinct stocks. The supplied history and the discovered history each call a real public producer, then observe at most one mutation. The registered claims cover every signed Java integer and both Boolean choices. The raw-field comparison has its own domain.

Inspect the registered claims with `python3 examples/tools/build.py --plan 397`. Run the public JVM controls with `python3 examples/tools/validate_example.py 397 --replay`. The receiver campaign also runs the checker’s `construct` command on the receiver type and an observer taking that type.
