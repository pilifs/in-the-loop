# First matching 64-bit Guava array element

The released Guava method returns the first index of a target and preserves its input. A deliberately reversed search returns the last match. At maximum lengths 8 and 64, strict native checking established all six expected first-match and preservation properties and refuted the two first-match claims for the reversed search. The direct JVM controls exercised 1,364 array/target combinations per revision. [Frozen claims](milestones.json) · [Bounded proof receipts](receipts)

The first attempt through the public induction rule stopped at the long-array descriptor. Reading the compiled 64-bit loads and signed comparison let the original prefix invariant, heap frame and termination proof carry over. Lengths, indices and the decreasing measure remain Java `int`s. The solver returned three satisfiable domain checks, including maximum legal length and distinct elements with identical low 32 bits. It found no counterexample in the eight checks for safety, exits, preservation and termination.
